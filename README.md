## 📌 Project Overview
AttendPro is a feature-packed student attendance tracking and management web platform built using pure **HTML5, CSS3, and JavaScript**. It helps educational institutions track daily student attendance, manage class strengths, handle leave approvals, generate exportable PDF/CSV reports, and view detailed analytical dashboards.

---

## 🚀 Key Features
- **Dashboard Overview:** Displays daily attendance counts (Present, Absent, Late, Leave) and interactive doughnut summary chart.
- **Student Management (CRUD):** Add, update, search, filter, and remove student profiles.
- **Class Management:** View classes, sections, assigned teachers, and total class strength.
- **Daily Attendance Marking:** Batch or individual status toggling with remarks and single-click "Mark All Present".
- **Attendance Reports:** View and filter class logs by date; export reports to `.CSV`.
- **Student Attendance History:** Check individual performance percentages and log history.
- **Analytics & Insights:** Weekly attendance trend lines and pie charts using Chart.js.
- **Leave Management:** Submit leave applications and approve/reject requests.
- **Bonus Features:** LocalStorage persistence, Dark Mode, Toast notifications, and fully responsive navigation bar.
